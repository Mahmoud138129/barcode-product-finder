# دليل المنتجات — Barcode Scanner (Frontend فقط)

موقع ثابت باستخدام HTML وCSS وJavaScript، يقرأ الباركود من كاميرا الموبايل ويبحث في ملف CSV مرفوع مع الموقع. لا يوجد Backend ولا قاعدة بيانات مدفوعة.

## محتويات المشروع
- `index.html` — واجهة الموقع.
- `styles.css` — التصميم المتجاوب.
- `app.js` — قارئ الباركود والبحث داخل CSV.
- `data/products.csv` — قاعدة بيانات المنتجات المنشورة.
- `product-template.xlsx` — قالب Excel لإضافة المنتجات وتحديثها.

## الأعمدة المدعومة في Excel / CSV
- `barcode` (مطلوب): رقم الباركود. اجعل العمود من نوع **Text** في Excel حتى لا تضيع الأصفار الأولى.
- `name` (مطلوب عمليًا): اسم المنتج.
- `brand`: الماركة.
- `category`: التصنيف.
- `size`: الحجم أو الوزن.
- `price`: السعر.
- `quantity`: الكمية.
- `location`: مكان التخزين.
- `supplier`: المورد.
- `description`: تفاصيل إضافية.
- `image_url`: رابط صورة عام يبدأ بـ `https://`.

## إضافة منتجات أو تحديثها
1. افتح `product-template.xlsx` في Excel.
2. اكتب المنتجات في ورقة `Products`، ولا تغيّر أسماء الأعمدة في الصف الأول.
3. حدّد عمود `barcode` واجعله **Text** قبل كتابة الأرقام.
4. من Excel اختر **Save As** ثم `CSV UTF-8 (Comma delimited) (*.csv)`.
5. سمّ الملف `products.csv` وضعه داخل مجلد `data` بدل الملف الحالي.
6. ارفع التغييرات إلى مستودع GitHub نفسه. بعد اكتمال النشر، افتح الرابط واعمل تحديثًا للصفحة.

> لا تحفظ ملف Excel نفسه بصيغة CSV وتفترض أن الملفين سيبقيا معًا؛ احتفظ بقالب XLSX، وصدّر نسخة CSV منفصلة للموقع. راجع أن فاصل CSV هو الفاصلة `,` وأن الترميز UTF-8.

## النشر المجاني على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub، مثل `barcode-product-finder`.
2. ارفع **محتويات** هذا المجلد إلى جذر المستودع (يجب أن يكون `index.html` في الجذر).
3. من المستودع افتح **Settings → Pages**.
4. في **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.
6. انتظر حتى يظهر رابط Pages في إعدادات Pages. افتحه من الموبايل.
7. اضغط «ابدأ المسح بالكاميرا» واسمح بالوصول للكاميرا.

## ملاحظات مهمة
- GitHub Pages يقدم استضافة للملفات الثابتة فقط، وليس Backend.
- قارئ الكاميرا يحتاج HTTPS؛ رابط GitHub Pages يدعم ذلك.
- يعتمد الموقع على تحميل مكتبة ZXing من CDN عند فتح الصفحة، ولذلك يحتاج الإنترنت لقراءة الكاميرا في هذا الإصدار.
- بيانات المنتجات في `data/products.csv` ستكون عامة لأي شخص يستطيع الوصول للموقع؛ لا تضع أسعارًا أو معلومات مخزون سرية.
- لا توجد تكلفة تشغيل مقصودة في هذا التصميم، لكن شروط وحدود الخدمات الخارجية قد تتغير.
- يجب أن يكون رقم الباركود فريدًا لكل منتج؛ لو تكرر الرقم، آخر صف في CSV هو الذي سيظهر.
